Como funciona por dentro

JavaScript puro, sem frameworks. O CEP é resolvido em endereço e código IBGE pela API ViaCEP, o endereço vira coordenadas pela API Nominatim (OpenStreetMap), a Open-Meteo devolve a temperatura atual e a previsão dos próximos dias, e o INMET informa se há algum alerta oficial pra região — tudo em cadeia, automático.
